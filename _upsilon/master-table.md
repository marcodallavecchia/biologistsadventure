## Artikeln

| Nominativ | Akkusativ |        Dativ         |
| :-------: | :-------: | :------------------: |
|    der    |    den    |         dem          |
|    die    |    die    |         der          |
|    das    |    das    |         dem          |
| die (pl.) |    die    | den + n (after noun) |

## W-Frage

| Nominativ  | Akkusativ        | Dativ              |
| ---------- | ---------------- | ------------------ |
| Wer        | Wen              | Wem                |
| Wo (Where) | Wohin (where to) | Woher (Where from) |
| Welche     | Welchen          | Welcher            |

### Welche

Behaves like an article so it changes to Dativ / Akkusativ !

1. **Welchen** Kaffe trinkst du?
2. **Welcher** Kaffe ist Kolumbianisch?
